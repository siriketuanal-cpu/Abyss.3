# ルナビィ（LUNABY）

**ルナビィ（LUNABY）**は、Dot AbyssとSTAR LEAPを扱う、静的・軽量な個人用タイマーです。GitHub Pagesを含む静的ホスティングで動作し、外部フォントや外部ライブラリを必要としません。

## 完全v2版

この公開版は、`lunaby:state:v2`だけを読み書きする**v2専用版**です。旧形式の保存・互換モジュール・自動移行は公開物に含みません。

> 有効な`lunaby:state:v2`があるブラウザでは通常起動します。保存がない、または破損している場合は、データを書き換えずに安全停止画面を表示します。

## 主な仕様

| 対象 | 契約 |
|---|---|
| Dot Abyssスタミナ | ランク連動の上限、3分ごとの回復、現在値直接入力、全回復予定時刻。現在値は自然幅、`/`と上限値は固定座標で揃える。満タン時は時刻の時側で手入力、分側で40計算を行う。 |
| 放置報酬 | 12時間上限、二段階タップ操作、満タン・残り2時間未満の視認表示。タイマーはスタミナ表示とデイリー操作域の間で中央に置く。 |
| デイリー | 二段階操作。完了時はAbyss.2由来の太い`✔`を表示。朝5時を跨いだ次回起動時だけ完了状態をリセットする。 |
| スターリープ討伐依頼 | 上限80、12分ごとに1回復、現在値直接入力、全回復予定時刻。 |
| 御大樹の恵み | 上限4、6時間ごとに1回復、`123`または`1:23`で全回復残り時間を入力。 |
| 数字表示 | Abyss.2と同じ丸み書体スタックと等幅数字指定を使用。 |
| Dot Abyssの枠判別 | 上境界線だけを、1・2枠の月青、3・4枠の薄紫、5・6枠の青緑で分ける。 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | v2専用のアプリ入口。 |
| `text-list-v2-only-entry.mjs` | 有効なv2保存だけを読み込み、主UIへ接続する入口。 |
| `text-list-v2-only-gate.mjs` | 保存なし・破損時の安全停止表示。 |
| `text-list.js` / `text-list.css` | 高密度UI、二段階操作、局所DOM更新。 |
| `abyss-runtime-core.mjs` | Dot Abyssの回復・放置報酬計算コア。 |
| `starleap-state.mjs` / `starleap-lite-core.mjs` | STAR LEAPの保存正規化と計算コア。 |
| `lunaby-v2-store.mjs` | v2保存の検証・局所保存アダプタ。配列位置は名前付き定数で管理し、保存形式は固定。 |
| `update.html` | 保存やService Workerを操作せず、新世代入口へ戻る手動更新ページ。 |

## 使用上の確認

更新後は、最初に表示値・現在値入力・二段階デイリー操作・ページ再読込後の保存復元を確認してください。手動更新が必要な場合は、左上の`LUNABY`から`update.html`を開きます。
