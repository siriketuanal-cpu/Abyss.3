# ルナビィ（LUNABY）

**ルナビィ（LUNABY）**は、Dot Abyssを中心にした高密度・静的・軽量のタイマーです。月と星の光をまとった深淵の案内役「ルナビィ」の名前を、アプリ名とアイコンの子の名前にしています。ビルド工程や外部依存なしで、GitHub Pagesを含む任意の静的ホスティングで動作します。

## 主な仕様

| 対象 | 契約 |
|---|---|
| Dot Abyssスタミナ | ランク連動の上限、3分ごとの回復、現在値直接入力、予定時刻表示。 |
| 放置報酬 | 12時間上限、二段階タップ操作、デイリーマーク。 |
| スターリープ討伐依頼 | 上限80、**12分**ごとに1回復、現在値直接入力、全回復予定時刻表示。 |
| 御大樹の恵み | 上限4、**6時間**ごとに1回復、`123`または`1:23`で全回復残り時間を入力。 |
| 保存 | 既存の`localStorage`キー`dotabyss:unified:v1`を維持。 |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 通常のアプリ入口。 |
| `text-list.html` | 互換用の同一入口。 |
| `text-list.js` / `text-list.css` | 高密度UIと局所DOM更新。 |
| `abyss-lite-core.mjs` | Dot Abyssの保存互換・計算・分更新コア。 |
| `starleap-lite-core.mjs` | スターリープの12分／6時間計算コア。 |
| `update.html` | 旧Service Workerと関連キャッシュを解除して入口へ戻る手動更新ページ。 |
| `manifest.json` / `icon-*.png` | ルナビィ専用のPWA設定と新アプリアイコン。 |

新アイコンは、青い深淵の小さなマスコットに星の瞳、月と星のアクセントを組み合わせたデザインです。小さなランチャー表示でも輪郭を判別しやすいよう、暗い背景と明るいシアンの差を大きくしています。

## 配置と確認

リポジトリのルートへこの一式を置き、GitHub Pagesなどの静的ホスティングを有効にしてください。`index.html`を開けば動作します。最初に表示値、入力、日次マーク、ページを開き直したあとの保存復元を確認してください。

> `dotabyss:unified:v1`には既存データがある場合があります。公開前に別ブラウザプロファイルまたは開発者ツールで読み込み互換を確認し、元のAbyss.2データを削除しないでください。
